# Настя и Викутория

Проект визуальной новеллы «Настя и Викутория».

## Структура проекта

- `index.html` — HTML-файл проекта.
- `css/style.css` — стили.
- `js/game.js` — файл для будущей игровой логики.
- `assets/images/backgrounds/` — фоны.
- `assets/images/characters/` — изображения персонажей.
- `assets/audio/` — аудиофайлы.

Создана базовая структура без игрового кода, изображений и аудио. Файлы `.gitkeep` сохраняют пустые папки в Git.
